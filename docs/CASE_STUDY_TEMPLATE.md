# Case Study — QA & Debugging | Code Shield

> **Projeto educacional com falhas intencionalmente inseridas.** Não representa auditoria de cliente real.

## Contexto
Um checkout fictício de e-commerce apresentava inconsistências no total, na validação de dados e no processamento de pedidos. O objetivo foi mostrar o ciclo completo de qualidade.

## Meu papel
Engenharia de QA, desenho de casos de teste, automação E2E, diagnóstico, correções, regressão e documentação.
